¿Qué es HSRP?

HSRP (Hot Standby Router Protocol) es un protocolo de redundancia de primer salto desarrollado por Cisco. Su principal objetivo es proporcionar alta disponibilidad en la puerta de enlace predeterminada de una red, evitando que los dispositivos pierdan la comunicación cuando un router presenta una falla.

HSRP funciona mediante un grupo de dos o más routers que trabajan juntos como si fueran una sola puerta de enlace lógica. Para lograrlo, los routers comparten una dirección IP virtual y una dirección MAC virtual. Los dispositivos de la red, como computadoras, servidores e impresoras, utilizan esta IP virtual como su gateway predeterminado.

¿Cómo funciona HSRP?

Dentro del grupo HSRP, un router toma el papel de Active y es responsable de reenviar el tráfico de los dispositivos hacia otras redes. Otro router adopta el estado de Standby y permanece preparado para asumir la función principal si el router Active deja de funcionar.

Los routers intercambian mensajes de control llamados Hello para comprobar que los miembros del grupo continúan disponibles. Cuando el router Standby detecta que el Active ya no responde, puede asumir automáticamente el estado Active y comenzar a utilizar la IP y MAC virtuales.

Elementos principales de HSRP

  • IP virtual: Es la dirección que utilizan los dispositivos de la LAN como puerta de enlace predeterminada.
  • MAC virtual: Es una dirección MAC asociada al grupo HSRP que permite identificar la puerta de enlace virtual.
  • Router Active: Es el router que actualmente procesa el tráfico de los dispositivos de la red.
  • Router Standby: Es el router de respaldo que permanece preparado para tomar el control.
  • Grupo HSRP: Identifica a los routers que participan en la misma configuración de redundancia.
  • Prioridad: Determina qué router tiene preferencia para convertirse en Active. Un valor de prioridad mayor tiene mayor preferencia.

¿Qué sucede si falla el router Active?

Si el router Active deja de funcionar, el router Standby detecta la falla mediante los mensajes de control de HSRP. Después de comprobar que el Active ya no está disponible, el Standby cambia al estado Active y comienza a responder utilizando la misma IP virtual.

Una de las principales ventajas es que los dispositivos de la LAN no necesitan cambiar su configuración. Las computadoras continúan utilizando la misma puerta de enlace predeterminada, mientras que HSRP se encarga de realizar el cambio entre routers.

¿Para qué sirve HSRP?

HSRP se utiliza principalmente para aumentar la disponibilidad y confiabilidad de una red. Es especialmente útil en redes empresariales donde una interrupción de la puerta de enlace puede afectar a muchos usuarios y servicios.

Ventajas de HSRP

  • Proporciona redundancia en la puerta de enlace predeterminada.
  • Reduce el tiempo de interrupción cuando un router falla.
  • Permite utilizar una IP virtual como gateway.
  • Los usuarios no necesitan modificar su configuración de red.
  • Permite establecer prioridades entre los routers.
  • Mejora la disponibilidad y confiabilidad de la red.
  • Es compatible con equipos y tecnologías de redes Cisco.

¿Cómo funciona?

Toca cada paso para ver el detalle.

Se conectan los routers

Router A (192.168.1.2) y Router B (192.168.1.3) están en la misma red y pertenecen al grupo HSRP 10, con IP virtual 192.168.1.1.

Se elige el router activo

Gana la prioridad más alta (por defecto 100). En empate gana la IP física más alta. Router A queda Active y Router B Standby.

Los equipos usan la IP virtual

Los PCs usan 192.168.1.1 como gateway, nunca 192.168.1.2 ni 192.168.1.3.

Los routers intercambian mensajes Hello

Se envían por multicast 224.0.0.2 (UDP 1985) cada 3 segundos para que el Standby sepa que el Active sigue vivo.

Si Router A falla, Router B toma el control

Si el Standby no recibe Hello durante el hold time (10 s por defecto), pasa de Standby a Active y responde por 192.168.1.1.

Conceptos clave

Mueve el mouse sobre las tarjetas y toca una para girarla.

Activetoca para girarRouter que da el servicio de gateway y reenvía el tráfico hacia la IP virtual.
Standbytoca para girarRouter preparado para sustituir al activo; escucha sus mensajes Hello.
IP virtualtoca para girarDirección que usan los dispositivos como gateway. Aquí: 192.168.1.1.
Grupo HSRPtoca para girarIdentificador del grupo de redundancia. Todos los routers usan el mismo número (10).
Prioritytoca para girarValor de 0 a 255 (por defecto 100). El más alto se convierte en Active.
Preempttoca para girarPermite que un router de mayor prioridad recupere el rol Active al volver a la red.
Hello y Holdtoca para girarHello cada 3 s; si no llegan en 10 s, el Standby asume el rol Active.
Tracktoca para girarMonitorea otra interfaz (por ejemplo hacia el ISP) y baja la prioridad si cae.

Configuración en Cisco IOS

Grupo 10, IP virtual 192.168.1.1. Router A con prioridad 110 y Router B con 100.

Verifica con show standby o show standby brief. Para probar la redundancia, haz ping a 192.168.1.1 desde el PC y apaga la interfaz del Router A con shutdown.
